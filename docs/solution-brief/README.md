# SysCorpus product and vision overview

Current working collateral, dated August 27, 2026.

- `index.html` is the screen and browser-print version.
- `syscorpus-product-overview.pdf` is the ready-to-print, six-page US Letter version.

## Recommended print settings

- Paper: US Letter, ordinary white paper
- Color: color
- Scale: 100% or Actual Size
- Two-sided: on, flip on long edge
- Headers and footers: off
- Background graphics: on

The PDF already includes its own page numbers and contact footer. It is six pages, so duplex printing produces three sheets.

The current product screenshots are direct, light-mode browser captures from a development map, not announcements of a public demo subject. They use the viewer's own zoom and a focused browser capture area; no enlargement, sharpening, recoloring, or other screenshot post-processing is applied. Replace them with the first graduated public-map captures when those exist.
