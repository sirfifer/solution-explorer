# Enrichment architecture records

The implemented enrichment contracts live in the analyzer, schemas, tests, and current public documentation. Detailed subject-specific run records, incident narratives, calibration artifacts, and forward demo plans are intentionally excluded from the tracked repository because they can disclose unpublished validation subjects.

Those working records are retained locally under the ignored `.local-private/demo-planning/` tree. They are not required to build, test, or operate SysCorpus.

Current public guarantees remain test-backed: evidence-bound claims, explicit gaps, metered provider calls, resumable runs, deterministic validation, provider portability, and no change to the default non-enrichment output path.
