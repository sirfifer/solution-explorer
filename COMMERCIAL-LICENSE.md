# Commercial licensing

Solution Explorer is source available under the
[PolyForm Noncommercial License 1.0.0](LICENSE). You can read it, run it, study
it, modify it, and share it, for noncommercial purposes.

**Commercial use requires a written license from the copyright holder.** That
includes running Solution Explorer on a company's own source code, using it
inside a commercial product or service, using its output in commercial work
product, and using it in the course of paid consulting. If a for-profit
organization benefits from it, it needs a license.

This page is not itself a license and grants nothing. It explains how to get one.

## Who needs to ask

| You are | Do you need to ask? |
| --- | --- |
| An individual, on your own projects, with no commercial application | No |
| A charity, school, public research body, public safety or health body, environmental organization, or government institution | No |
| A company wanting to evaluate it, even briefly, even in a sandbox | Yes |
| A company running it internally on its own code | Yes |
| A consultancy using it on client work | Yes |
| Anyone embedding it in a product or service they sell | Yes |
| An open source project with any commercial dimension | Yes, and the answer is usually yes |

Evaluation and proof of concept access is normal and is granted routinely. It is
simply granted explicitly rather than assumed. Expect a short scope and a fixed
term, the same shape any vendor's POC agreement takes.

## How to ask

Email **licensing@syscorpus.com**, or open a GitHub issue titled
`License request: <organization>` if the details are not sensitive.

Include:

1. **Organization**, legal name and website.
2. **What you want to do with it.** Evaluate, run internally, embed, resell.
3. **Scope.** Roughly how many engineers, how many repositories, and whether
   this is production or evaluation.
4. **Deployment.** Self-hosted on your infrastructure, or something else.
5. **Timeline.** When you need an answer, and for how long.

The aim is a response within five business days.

## What is available

- **Evaluation grant.** Narrow, time-boxed, non-production, free. For deciding
  whether the tool is worth buying.
- **Internal use license.** Run it on your own code, in production, priced per
  organization rather than per seat.
- **OEM and embedding license.** Ship its capability inside your own product.
  Negotiated per deal.
- **Open source and public benefit grant.** Free use for projects and
  organizations whose work warrants it. Granted case by case, and generously in
  practice. See [docs/commercial/GRANT-POLICY.md](docs/commercial/GRANT-POLICY.md)
  for the criteria used.

Pricing is quoted per engagement. There is no public rate card yet.

## Compliance

If you discover that your organization has been using Solution Explorer without
a license, contact us. The license itself provides 32 days from written notice
to come into compliance without losing your rights. The intent here is to know
who the users are and to be paid by companies, not to litigate.
