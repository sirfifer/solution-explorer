# Additional permissions

This file is the public register of permissions granted **beyond** the
[LICENSE](LICENSE). It can only add permissions. Nothing here removes or
narrows any right the license already grants.

## Standing permissions

**None.** Beyond what the PolyForm Noncommercial License 1.0.0 grants on its
own, there is no automatic permission for any organization, project, or
category of user. This includes evaluation, proof of concept, pilot, and
internal sandbox use by a company. Those are available and are frequently
granted, but each one is granted explicitly and in writing. See
[COMMERCIAL-LICENSE.md](COMMERCIAL-LICENSE.md) for how to ask.

Being open source does not by itself confer permission. Many open source
projects will be granted free use on request. That is a decision made per
project, not a blanket rule.

## What the license already grants, without asking

For clarity, the following need no additional permission because
[LICENSE](LICENSE) already covers them:

- Personal use for research, experiment, testing for the benefit of public
  knowledge, personal study, private entertainment, hobby projects, amateur
  pursuits, or religious observance, with no anticipated commercial
  application.
- Use by any charitable organization, educational institution, public research
  organization, public safety or health organization, environmental protection
  organization, or government institution, regardless of funding source.

Read the license text itself for the controlling language. The summary above is
not a substitute for it.

## Granted permissions

No additional permissions have been granted to date.

When one is granted it is recorded here, in this format, so that the recipient's
legal and compliance teams can verify it from the repository itself:

```
### <Grantee legal name>

- Granted: <YYYY-MM-DD>
- Scope: <exactly what is permitted, e.g. "internal non-production evaluation
  of Solution Explorer by employees of Grantee, on Grantee's own source code">
- Versions covered: <version range or "all versions published during the term">
- Term: <fixed end date, or "until revoked in writing">
- Conditions: <attribution, no redistribution, feedback, whatever applies>
- Reference: <signed grant document or issue reference>
```

A permission recorded here is the authoritative public record of that grant. If
a signed grant document and this file disagree, the signed document controls.

## Revocation

A permission with a stated term ends on that date without further notice. A
permission granted "until revoked" ends when the copyright holder gives the
grantee written notice, and this file is updated to record the end date. Ending
a permission does not affect the grantee's rights under the license itself.
